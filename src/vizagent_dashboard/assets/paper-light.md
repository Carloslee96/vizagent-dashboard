# Paper Light

## Visual Theme

暖白纸张背景与墨色文字，适合经营汇报和需要长时间阅读的分析页面。

## Color Palette

| Token | Value | Purpose |
|---|---|---|
| `--bg-primary` | `#f5f2eb` | 页面背景 |
| `--bg-card` | `#fffdf8` | 面板 |
| `--bg-elevated` | `#ebe5da` | 悬浮层 |
| `--text-primary` | `#25231f` | 主文字 |
| `--text-secondary` | `#6f6a61` | 次文字 |
| `--border-subtle` | `#d8d1c5` | 边框 |
| `--border-strong` | `#81786c` | 强边框 |
| `--accent-primary` | `#315d8a` | 强调 |

| `--radius-card` | `8px` | 卡片圆角 |
